# Спека: «Накачка» — фигуры работают на ресурсе, добытом в бою вблизи

Дата: 2026-10-11 · Самостоятельный подпроект, не блокирует «виды врагов» · Статус: на ревью

## 1. Зачем это

Плейтест №1 показал главную болезнь суммонера: стоять выгодно, и игра играется сама. Давление
врагов (B5/B7) сделало стояние смертельным, но не сделало фигуры инструментом. Фигура по-прежнему
живёт собственной жизнью:

- турель встаёт в точку игрока и сама выбирает ближайшую цель (`spawnForCard` → `addAlly('turret', this.pos)`,
  `Ally.stepTurret`);
- анти-АФК правило «стоящий игрок не должен побеждать чужими руками» привязано только к крыльям
  (`idleGraceMs`, `playerActive` в `Ally.step`); устройства не гаснут никогда;
- у врагов единственная цель — игрок (`Enemy.step(dt, playerPos, …)`), поэтому фигура не может быть
  инструментом контроля внимания;
- карта выдаёт фигуру целиком в момент выбора: ценность получена, а не заработана.

Цель подпроекта: **у фигур появляется общая энергия «Ток». Её добывает только сам игрок и только в
опасной близости к врагу. Нет ближнего боя — фигуры молчат.**

Инварианты:

1. Без игрока фигура не работает — не «слабее», а молчит.
2. Сила добывается риском (дистанция до врага), а не временем.
3. Новых кнопок нет: управление — позиция и темп игрока. Мобильная эргономика не растёт.

Философский источник — Solomon (Deadlock): там фигуры **двигают**, и кулдаун начинается, когда
владение фигурой закончилось. Кит не копируем; берём принцип «фигура работает, пока игрок ею занят».

## 2. Границы

**Входит:**

- единый пул «Ток» на все фигуры;
- начисление только от урона игрока, с риск-премией по дистанции до задетого врага;
- расход на каждое действие фигуры (выстрел, укус, подрыв);
- затухание пула и потолок;
- признак «владелец выстрела» в общем пуле снарядов;
- читаемость: шкала в HUD, тусклые фигуры без энергии, разовый тост;
- версия записи прогона;
- чистый модуль с тестами и бот-замеры.

**Не входит (следующие шаги):**

- реакция врагов на фигуры (агро): здесь только интерфейсный задел, поведение — вместе с видами врагов;
- маршруты и движение фигур («Чертёж») и приманка внимания («Приманка») — отдельные подпроекты;
- карты на Ток (как с бронёй: сначала плейтест, потом решать);
- пересборка веток, профессий и «класс до забега».

## 3. Решения

### 3.1 Один пул на весь выводок

Одна шкала `Ток`, общая для турелей, духов, мотов и дронов. Пул виден в HUD и на самих фигурах
(тусклость). Отвергнуто: шкала на каждую фигуру — 6–7 полосок грузят восприятие, на это уже
жаловался плейтест №1.

### 3.2 Начисление: урон игрока, а не фигур

Пул кормит только урон, который нанёс **игрок** (свой ствол и его разрывы). Урон фигур не кормит
пул: иначе выводок сам себя оплачивает, и автопилот возвращается через чёрный ход. Убийства ничего
не добавляют сверх урона; опыт, уровни и единственный путь смерти врага не меняются.

### 3.3 Риск-премия по дистанции

Награда за попадание линейно падает от 1 до 0 по расстоянию от игрока до задетого врага: полная,
если ближе `nearFactor` меньшей стороны поля; ноль, если дальше `farFactor`. Стрельба с безопасного
края по дальним целям пул не растит. Разрыв считается по каждому задетому врагу отдельно: у каждого
своя дистанция.

Отвергнуто: фиксированная награда независимо от дистанции (риск не требуется); премия «за врагов
рядом вообще» без дистанции попадания (не учит стрелять вплотную).

### 3.4 Расход: каждое действие фигуры

Выстрел турели, выстрел духа, укус мота и подрыв дрона списывают Ток (числа — `TUNING.charge.cost*`).
Тока нет — действие не происходит:

- турель и дух не стреляют (кулдаун продолжает идти: фигура не «копит» выстрелы и не бьёт очередью,
  когда пул появился, — она просто попадает в свой обычный темп);
- мот не начинает преследование;
- дрон в контакте не срабатывает и не разряжается — мина остаётся заряженной и ждёт следующего контакта.

Крылья дополнительно сохраняют прежнее условие `playerActive`: для них обязателен и движущийся игрок,
и Ток. Отвергнуто: ручная кнопка «залп» (новая кнопка на телефоне, конфликт с дэшем и стиком);
действие «в долг» без списания (автопилот возвращается).

### 3.5 Затухание

Пул медленно тает всегда (`decayPerSec`), поэтому «нафармить впрок и бегать» не работает: полный пул —
буст-окно в ближнем бою, а не капитал. Потолок `cap` не даёт расти бесконечно. Вне боя пул не растёт
по определению (кормить его нечем).

### 3.6 Читаемость

- Шкала Тока появляется в HUD, когда в билде есть хоть одна фигура; в чисто инженерном забеге она не
  нужна и не показывается.
- Фигура без запаса тускнеет — так же, как сейчас гаснет крыло без движения, чтобы причина читалась
  без текста.
- Один раз за забег тост «ФИГУРЫ БЕЗ ПИТАНИЯ» при первой нехватке Тока — тем же механизмом, что тост
  крыльев.

### 3.7 Владелец выстрела в общем пуле

Пул снарядов общий для игрока и фигур (`Projectiles`), поэтому признак владельца обязан ехать вместе
со снарядом: `ShotSpec.byPlayer`, поле снаряда и `HitTargets.damage(enemy, amount, byPlayer)`. Сцена
по этому признаку начисляет Ток и только по нему. Разрыв — тоже снаряд: его урон идёт с тем же
признаком. Второй пул (снаряды врага из Task 6) не затрагивается: у него свой путь урона.

### 3.8 Запись прогона

Правила забега меняются → `RunRecord.version`: **3 → 4**. Если к моменту реализации «виды врагов» уже
подняли версию до 4, «Накачка» поднимает до 5: складывать прогоны разных правил в одну таблицу нельзя.

### 3.9 Задел под агро врагов

Здесь враг по-прежнему видит только игрока: поведение не трогаем. Задел на будущее: при написании
`enemyBrain` (подпроект «виды врагов») в его контекст добавляется представление фигур — позиция и
нормированный заряд, — чтобы `shooter` и `tank` могли переключаться на светящиеся фигуры. Поведение
и агро-веса — отдельный план.

## 4. Архитектура

Новый чистый модуль `src/systems/charge.ts` (без Phaser, тестируется `node:test`):

```
export interface Charge { amount: number }
function createCharge(): Charge
function riskFactor(distFactor: number): number
function addForHit(c: Charge, damage: number, distFactor: number): void
function spend(c: Charge, cost: number): boolean
function stepCharge(c: Charge, dt: number): void
function chargeNorm(c: Charge): number
```

`addForHit` начисляет `damage × perDamage × riskFactor(distFactor)` и не превышает `cap`; `spend`
возвращает false, если Тока меньше цены, и ничего не списывает; `stepCharge` гасит пул, не уходя
ниже нуля.

Правки по файлам:

- `src/config/tuning.ts` — блок `charge`;
- `src/systems/projectiles.ts` — владелец выстрела в `ShotSpec`, `Projectile`, `HitTargets`;
- `src/systems/weapon.ts` — выстрелы игрока помечаются владельцем;
- `src/entities/ally.ts` — `AllyContext.charge`, расход перед действием, тусклость без запаса;
- `src/scenes/GameScene.ts` — начисление в `damage()` по признаку и дистанции, `stepCharge` в шаге,
  шкала и тост в HUD;
- `src/core/runRecord.ts` — версия записи.

Стартовые числа (`TUNING.charge`; уточняются замерами):

| Число | Старт | Смысл |
|---|---|---|
| `cap` | 20 | потолок пула |
| `perDamage` | 1 | Ток за единицу урона при полной риск-премии |
| `nearFactor` | 0.20 | ближе — полная награда |
| `farFactor` | 0.40 | дальше — ноль |
| `decayPerSec` | 1 | затухание |
| `costTurret` / `costSpirit` / `costMote` / `costDrone` | 1 / 1 / 1 / 2 | цена действий |

Ориентиры баланса (проверяются замером): базовый пистолет (≈3.8 урона/с в ближнем бою) устойчиво
оплачивает 1–2 фигуры; выводок из 3 турелей и 3 духов (≈7.8 действия/с) требует вложений в урон
ствола («Калибр»); полный пул — буст-окно 5–8 секунд.

## 5. Что меряем

Шагами симуляции (как забеги №2–4), а не на глаз:

1. ближний бой: пул растёт, выводок стреляет — урон фигур за 30 с;
2. дальний огонь по краю: прирост пула = 0, фигуры молчат после исчерпания;
3. без стрельбы вообще: пул в ноль за `cap / decayPerSec`, ноль действий фигур;
4. полный пул: сколько секунд стрельбы даёт выводок из 1 / 3 / 6 фигур;
5. старая стоянка 10–15 с: как раньше 0 убийств и 0 действий фигур;
6. старые замеры (контакт, дэш, кайтинг) не изменились.

Руками (десктоп и телефон): видно ли, почему фигуры молчат; не читается ли тусклость как обычная
перезарядка; не вырос ли HUD и не мешает ли шкала на узком поле.

## 6. Риски (эксплойты) и ответы

| Эксплойт | Ответ |
|---|---|
| «Нафармить впрок и бегать» | потолок + постоянное затухание |
| «Стрелять с безопасного края» | риск-премия: дальше `farFactor` — ноль |
| «Выводок играет сам» | урон фигур не кормит пул; без игрока пул только тает |
| «Больше фигур — не наказывается» | больше фигур — быстрее расход; потолок вывода задаётся картами и уроном ствола |
| «Стоять в толпе фигур» | правило прежнее: стоять смертельно (B5/B7), а Ток требует ближнего боя, то есть движения |
| «Пул ломает старые замеры» | правила врагов не меняются; замеры стоянки и кайтинга прогнать заново |

## 7. Критерий приёмки

- Тесты на `charge` зелёные; `npm test`, `npm run typecheck`, `npm run build` — EXIT=0.
- Замеры 1–6 воспроизводимы скриптом; числа записаны.
- Плейтест подтверждает: без ближнего боя фигуры молчат, и это понятно почему.
- Версия записи поднята; шкала читается на телефоне.
